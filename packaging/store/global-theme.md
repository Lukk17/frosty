# Frosty global theme

The global theme `com.github.lukk17.frosty` is part of Frosty, a frosted glass theme for KDE Plasma 6: https://github.com/Lukk17/frosty

It selects the Plasma Style `frosty`, the colors `Frosty`, the application style and window decoration Frosty, the icons `frosty` and the cursors `Sweet-cursors`, and has an optional desktop layout. The application style and window decoration are compiled plugins, so they come only with the Arch package `frosty` (https://aur.archlinux.org/packages/frosty). Every change and its date is listed in `look-and-feel/CHANGES.md` of the Frosty project.

The global theme is by lukk17, under GPL-3.0-or-later. `contents/colors` is the Frosty color scheme, a changed copy of the Layan colors by vinceliuice (https://github.com/vinceliuice/Layan-kde), under GPL-3.0-only, so the package as a whole is under GPL-3.0-only.
