# Sweet cursors

The cursor theme `Sweet-cursors` is used by Frosty, a frosted glass theme for KDE Plasma 6: https://github.com/Lukk17/frosty

It is an unchanged copy of `kde/cursors/Sweet-cursors` by EliverLara, from https://github.com/EliverLara/Sweet branch `dark-plasma-6` at commit `fa5229183093c078bebbc1b405d78909ffa18bb4`.

The cursors are compiled X cursor files. Their source, the SVG drawing and the build script, is in `vendor/cursors/source` of the Frosty project at the tag of this version, and upstream in `kde/cursors/src` and `kde/cursors/build.sh` of the same commit.
