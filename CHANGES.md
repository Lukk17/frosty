# Changes

The GNU GPL asks that modified files carry a notice of what was changed and when. The notices for this project are kept here and in the CHANGES.md file of each component, not in the source files. Points 1 to 12 below were made from 2026-10-20 to 2026-10-22. Every later point starts with the date of its change.

### 0.0.1, 2026-10-22, lukk17

The first release. Frosty 0.0.1 contains:

1. The Plasma Style `frosty`, a changed copy of the Layan Plasma Style, see [vendor/plasma-style/CHANGES.md](vendor/plasma-style/CHANGES.md).
2. The color scheme `Frosty.colors`, a changed copy of the Layan colors, see [vendor/color-scheme/CHANGES.md](vendor/color-scheme/CHANGES.md).
3. The application style and window decoration Frosty, a renamed copy of Darkly 0.5.41 with new defaults, see [vendor/style/CHANGES.md](vendor/style/CHANGES.md).
4. The icon theme `frosty`, made from Infinity-Dark-Icons, candy-icons and Sours-Full-Color, see [vendor/icons/CHANGES.md](vendor/icons/CHANGES.md).
5. An unchanged copy of the Sweet cursors, see [vendor/cursors/CHANGES.md](vendor/cursors/CHANGES.md).
6. The global theme `com.github.lukk17.frosty` with its desktop layout, see [look-and-feel/CHANGES.md](look-and-feel/CHANGES.md).
7. The Konsole color scheme Frosty Green, a changed copy of Konsole's Dark Pastels, see [vendor/konsole/CHANGES.md](vendor/konsole/CHANGES.md), and the Konsole profile [konsole/Frosty.profile](konsole/Frosty.profile), made from the owner's profile with `Name=Frosty`. Both are installed in `/usr/share/konsole`.
8. Defaults for Konsole and Dolphin in [xdg/konsolerc](xdg/konsolerc) and [xdg/dolphinrc](xdg/dolphinrc), installed in `/etc/xdg` and listed in the PKGBUILD `backup` array.
9. The command [bin/frosty-setup](bin/frosty-setup), installed as `/usr/bin/frosty-setup`, with its helper [lib/restore-widget-settings.js](lib/restore-widget-settings.js), installed in `/usr/share/frosty`. It saves and exports a konsave backup, installs the KDE Store widgets KDE Control Station, Compact Clock, Dockio, BatteryWatch and the AI usage widget, asks before it replaces the panels and desktop widgets, applies the Frosty global theme with or without its layout, copies the user's old widget settings into the new widgets of the same plugin, and prints the command `frosty-setup --undo` to go back. It writes the previous global theme and the backup name to `${XDG_STATE_HOME:-~/.local/state}/frosty/last-run`. `frosty-setup --undo` reads that record, shows the three steps and asks once, then applies the previous global theme with `plasma-apply-lookandfeel --apply`, brings back the backup with `konsave -a` and restarts Plasma with `systemctl --user restart plasma-plasmashell`. Without a record it prints these three commands to run by hand.
10. The install message [packaging/aur/frosty.install](packaging/aur/frosty.install), which pacman prints after an install or an upgrade and which tells the user to run `frosty-setup`.
11. The [PKGBUILD](PKGBUILD), [.SRCINFO](.SRCINFO), [LICENSES](LICENSES), [REUSE.toml](REUSE.toml), [CREDITS.md](CREDITS.md) and the documentation. The package depends on `bash`, `konsave` (AUR), `plasma-workspace` and `qt6-tools` for `frosty-setup`, and on the AUR package `plasma6-applets-appgrid` for the dock launcher.
12. No KWin settings and no fonts, because the owner's `kwinrc` has no `[Plugins]` or `[Effect-blur]` group and the owner's `kdeglobals` has no font keys.
13. (2026-10-26) The Konsole color scheme Frosty Green now enables blur with `Blur=true`, so the Konsole tool bar, tab bar and menu bar are frosted like in other applications, see [vendor/konsole/CHANGES.md](vendor/konsole/CHANGES.md).
14. (2026-11-07) Smoked glass: the color scheme `Frosty.colors` has darker, less see-through view, header and window colors, and solid text on inactive title bars, see [vendor/color-scheme/CHANGES.md](vendor/color-scheme/CHANGES.md). The Frosty style draws the Dolphin view at 75 percent and the Dolphin sidebar, tool bars, tab bars, menu bars and the title bar at 70 percent, see [vendor/style/CHANGES.md](vendor/style/CHANGES.md). File names in Dolphin over a white window behind it measured a contrast of 6.89 to 1 in a render, up from 2.4 to 1.
15. (2026-11-07) Qt Quick and Kirigami applications, such as filelight, System Monitor, KDE Connect, Haruna and Spectacle, now get KWin blur behind their see-through window, like widget applications. Frameless windows, popups, Plasma panels and popups, plasmashell and the applications in `OpaqueApps` are left as they were, see [vendor/style/CHANGES.md](vendor/style/CHANGES.md).
16. (2026-11-07) The remaining Layan greys follow the smoked glass. In `Frosty.colors` the `BackgroundAlternate` of `[Colors:Header]`, `[Colors:Header][Inactive]` and `[Colors:Window]` and `[WM] activeBackground` are now `21,23,24`, with the alpha 179 of `BackgroundNormal` in the two see-through groups, and the inactive `ForegroundActive` is solid. The color file of the Plasma Style, used by panels and popups, now has the same RGB values as `Frosty.colors` but stays solid, see [vendor/color-scheme/CHANGES.md](vendor/color-scheme/CHANGES.md) and [vendor/plasma-style/CHANGES.md](vendor/plasma-style/CHANGES.md).
17. (2026-11-10) One glass value: every see-through part is 65 percent covering. In `Frosty.colors` the alpha 179 is now 166, and the Frosty style draws the Dolphin view, the Dolphin sidebar, tool bars, tab bars, menu bars and the title bar at 65 percent, see [vendor/color-scheme/CHANGES.md](vendor/color-scheme/CHANGES.md) and [vendor/style/CHANGES.md](vendor/style/CHANGES.md). The color file of the Plasma Style is unchanged.
18. (2026-11-10) The Dolphin status bar, with the item count and the free space bar, is glass at `ToolBarOpacity` like the tool bars. Before, it showed the window background, which the style paints three times, so it looked solid, see [vendor/style/CHANGES.md](vendor/style/CHANGES.md).
19. (2026-11-10) The color file of the Plasma Style has the see-through alpha 166 of `Frosty.colors` in `BackgroundNormal` and `BackgroundAlternate` of `[Colors:Header][Inactive]` and `[Colors:Window]`. Widgets that fill their own cards with `Kirigami.Theme.backgroundColor`, such as KDE Control Station, now show 65 percent glass instead of solid black cards. The Plasma Style frames of panels, popups and widget backgrounds look the same as before, see [vendor/plasma-style/CHANGES.md](vendor/plasma-style/CHANGES.md).
20. (2026-11-10) Plain window areas, where no bar or view covers the window background, are 65 percent glass like the rest of the window. Before, every application with the Frosty style painted them three times, which covered 96 percent, see [vendor/style/CHANGES.md](vendor/style/CHANGES.md).
21. (2026-11-10) The glass is now 80 percent covering, up from the 65 percent of point 17. In `Frosty.colors` and in the color file of the Plasma Style the alpha 166 is now 204, and the Frosty style draws the Dolphin view, the Dolphin sidebar, the Dolphin status bar, tool bars, tab bars, menu bars, plain window areas and the title bar at 80 percent. Menus stay solid. See [vendor/color-scheme/CHANGES.md](vendor/color-scheme/CHANGES.md), [vendor/plasma-style/CHANGES.md](vendor/plasma-style/CHANGES.md) and [vendor/style/CHANGES.md](vendor/style/CHANGES.md).
22. (2026-11-10) An AUR recipe, [packaging/aur/PKGBUILD](packaging/aur/PKGBUILD), with `url`, the release archive `https://github.com/Lukk17/frosty/archive/refs/tags/v$pkgver.tar.gz` as its source and a `sha256sums` placeholder of 64 zeros that the release workflow replaces with `updpkgsums`.
